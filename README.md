# SmartSpend AI Dashboard

Build a modern, responsive web application called "SmartSpend AI".

SmartSpend AI is a smart expense tracking and budgeting application designed mainly for students.

The application should have these core features:

1. Dashboard

- Show total expenses

- Show monthly budget

- Show remaining budget

- Show spending percentage

- Show recent expenses

- Show a simple category-wise spending chart

2. Add Expense

- Amount

- Category: Food, Travel, Education, Shopping, Bills, Other

- Date

- Description

- Save expense

3. Expense Management

- Display all expenses in a clean table/list

- Allow users to edit and delete expenses

- Calculate total spending automatically

4. Budget

- Allow the user to set a monthly budget

- Show budget used and remaining amount

- Show a warning when spending approaches or exceeds the budget

5. Analytics

- Category-wise spending

- Weekly/monthly spending summary

- Simple charts

6. AI Insights

- Analyze the user's spending patterns

- Give simple personalized suggestions such as:

  "You spent more on food this week."

  "You are close to your monthly budget."

  "You could reduce shopping expenses to save more."

Design requirements:

- Professional and modern UI

- Student-friendly

- Clean dashboard

- Responsive for laptop and mobile

- Use the SmartSpend AI name and branding

- Use a clean dark teal, light mint and gold accent color palette

- Add proper navigation: Dashboard, Add Expense, Analytics, Budget

Important:

Keep the application simple and fully functional.

Do not add unnecessary complex features.

Make the core features work before adding extra features.
